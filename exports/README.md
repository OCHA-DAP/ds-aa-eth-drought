# Ethiopia Drought AA — SEAS5 historical trigger export

Raw historical SEAS5 forecast data and the backtested trigger record for the
in-development Ethiopia drought anticipatory action redesign. Generated by
`exploration/export_trigger_data.py`.

**Framework version:** 2026-06-09 (in development — not yet endorsed)
**Trigger basis:** SEAS5 seasonal forecast, zone-count at a 5-year per-zone return period
**Admin level:** admin-2 (zones)
**Reference period:** 1997–2025 (29 years); 2026 is the current forecast year
**SEAS5 source:** `public.seas5`, PROD Azure DB (ECMWF SEAS5 ensemble-mean precipitation)

Two independent seasonal windows are exported. Both are **purely SEAS5-driven**
(ERA5 / LEAP-WRSI / ASI / VHI are monitoring layers, not trigger components).

| window | column | issue month(s) | season | threshold |
|---|---|---|---|---|
| MAM (Belg) | `eth_drought_v1_wt1` | Feb | Mar–May | ≥ 15 zones @ ≥5yr RP |
| JJAS (Kiremt) | `eth_drought_v1_wt2` | Apr **or** May | Jun–Sep | ≥ 35 zones @ ≥5yr RP |

### `seas5_mam_perzone.csv` (1,860 rows)

Per-zone MAM seasonal totals from the Feb-issued SEAS5 forecast, with historical rank
and empirical return period.

| Column | Description |
|---|---|
| `year` | Season year (forecast valid year) |
| `pcode` | Admin-2 zone pcode |
| `issued_month` | Forecast issue month (2 = Feb) |
| `seasonal_total_mm` | Cumulative Mar–May forecast rainfall, mm (monthly ensemble mean × days-in-month, summed) |
| `rank` | Rank of this year's total within the zone (1 = driest), `method="min"` |
| `return_period` | `(n_years_ranked + 1) / rank` |
| `flagged_ge_5yr` | `return_period >= 5` |
| `n_years_ranked` | Size of the ranking pool (29 for historical years; 30 for 2026) |

- **62 MAM zones**, 29 historical years + 2026.

## Trigger logic

For each in-scope admin-2 zone, cumulative seasonal forecast rainfall is ranked against
the historical distribution. A zone "flags" when its ranked position corresponds to a
return period of ≥ 5 years (i.e. among the driest ~20% of years). The window fires when
the count of flagged zones meets the season threshold:

```
MAM  triggered ← count(zones with RP ≥ 5 in Feb forecast) ≥ 15
JJAS triggered ← count(RP ≥ 5 in Apr forecast) ≥ 35  OR  count(RP ≥ 5 in May forecast) ≥ 35
```

The 5-year per-zone return period (~20% annual exceedance per zone) is the building
block; the aggregate zone thresholds (15 / 35) are calibrated against years of confirmed
humanitarian drought impact to give a framework-level return period of ~5 years.

**Ranking pool.** Historical years (≤ 2025) are ranked on the historical-only pool
(n = 29). The current forecast year (2026) is ranked against the historical pool plus
itself (n = 30) and only *its own* counts are read off — history is never re-ranked by
the incoming forecast year. This matches the analysis notebooks and is required to
reproduce the endorsed backtest (e.g. JJAS 2009: April = 36 zones ≥ 35, so 2009 flags).

## Notes

- **JJAS Mar is monitoring context, not a trigger component.** The operative JJAS trigger
  keys off the Apr and May forecasts only (`trigger_issued_months = [4, 5]`). Mar zone
  counts are exported for transparency. This follows the JJAS summary notebook, which
  drops the Mar column from the final table and draws the threshold line on Apr/May only.
  Whether a single issue-month suffices or the two must agree is an open framework
  question (see the KB `eth-drought` page); as coded, either month alone fires the window.
- **Both windows are SEAS5-only.** In the summary notebooks all ERA5 / WRSI / ASI / VHI
  columns are commented out of the merge and excluded from the trigger mask; they are
  validation layers, not trigger inputs.
- **Zone lists** (which admin-2 pcodes belong to each season) live on the DEV blob
  (`ds-aa-eth-drought/exploration/Ethiopia MAM zones.csv`, `... JJAS zones.csv`) and are
  not committed to this repo.
- This is an **in-development** trigger design with no endorsed framework document and no
  pre-committed funding. The 2020-endorsed Ethiopia drought AA used a different
  (AND-logic IPC + rainfall) trigger.
- Source notebooks: `analysis/05_4_drought_trigger_summary_mam.ipynb`,
  `analysis/05_5_drought_trigger_summary_jjas.ipynb`.
